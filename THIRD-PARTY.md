# Tredjepartsdelar

Webbappens HTML, CSS, JavaScript, ikoner och Excel-skrivare har skapats för det här projektet. Webbappen hämtar inga tredjepartsbibliotek, teckensnitt eller andra resurser under användning.

Androidbygget använder följande externa byggdelar:

- Gradle Wrapper 8.13: [Gradle](https://github.com/gradle/gradle), Apache License 2.0. Den medföljande `gradle-wrapper.jar` har hämtats från Gradles officiella tagg `v8.13.0`. SHA-256: `81a82aaea5abcc8ff68b3dfcb58b3c3c429378efd98e7433460610fecd7ae45f`.
- Android Gradle Plugin 8.13.0 och AndroidX WebKit 1.14.0: [Android Open Source Project](https://source.android.com/), Apache License 2.0. Dessa hämtas av Gradle vid första bygget; de ingår inte i webbappens körning.
